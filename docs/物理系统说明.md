# 物理系统使用说明

本文件说明当前已实现的物理能力、接口用法和明确边界。设计阶段划分见[物理系统实施计划](物理系统实施计划.md)；这里只描述已经通过测试的行为。

首版覆盖：碰撞形状与射线、静态碰撞世界与查询、角色控制器（胶囊沿表面滑动）、动态刚体球（顺序冲量 + 休眠）、
碰撞层/掩码、固定步长与渲染插值、碰撞体可视化。**不包含**关节、软体、布料、CCD、多线程、ECS 和场景存档。

## 运行示例

```powershell
runtime/examples/physics_demo/physics_demo.exe
```

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 沿摄像机方向移动角色（`Shift` 冲刺） |
| `Space` | 跳跃（仅在着地时生效） |
| 右键拖动 | 绕角色旋转摄像机 |
| `E` | 在角色前方生成一个动态刚体球 |
| `R` | 沿视线射线检测，在命中点前侧放置一个静态方块 |
| `G` | 对所有球施加向上冲量（唤醒休眠中的球） |
| `P` | 开关碰撞体可视化（半透明形状叠加） |
| `C` | 清空动态球与放置的方块 |
| `Escape` | 退出 |

场景内容：无限地面（平面）、20° 可行走斜坡、60° 陡坡、三级台阶、两个可被射线命中的方块。
角色可以用 `W`/`S` 沿斜坡上下滑动，撞上陡坡会下滑，跳跃后落回地面；生成的球会落地、滚动、互相碰撞并最终休眠。

## 模块与职责

| 文件 | 职责 |
| --- | --- |
| `src/physics/math/Aabb.*` | 轴对齐包围盒：相交、包含、扩展、合并、按矩阵变换 |
| `src/physics/math/Ray.*` | 射线：构造时归一化方向并校验 |
| `src/physics/math/Raycast.*` | 射线与球/盒/平面/竖直胶囊求交 |
| `src/physics/math/ClosestPoint.*` | 线段与 AABB 的最近点，供胶囊与盒体窄相位共用 |
| `src/physics/shapes/CollisionShape.*` | 碰撞形状：`SphereShape`/`BoxShape`/`CapsuleShape`/`PlaneShape`，构造时校验参数 |
| `src/physics/world/ShapeCollision.*` | 窄相位：世界变换、世界 AABB、支撑点、形状对接触、位姿归一化与分离方向 |
| `src/physics/world/PhysicsWorld.*` | 世界：注册/注销、broadphase、接触求解、休眠、查询、固定步长与插值 |
| `src/physics/character/CharacterController.*` | 角色移动：子步、沿表面滑动、着地判定与吸附 |
| `src/physics/body/PhysicsFilter.h` | 碰撞层/掩码与配对规则 |
| `src/physics/body/RigidBody.h` | 刚体参数与状态（纯数据） |
| `src/scene/components/PhysicsBodyComponent.*` | 把 GameObject 注册为静态碰撞体的组件 |

`physics` 只依赖 `glm` 和 `src/math/`，不依赖 Scene、Window 和 OpenGL：所有物理测试都能在无窗口的 `-L cpu` 分组里运行。

## 内部实现要点

- **宽相位接入步进**：`collectContacts` 用单轴（X）扫掠剪枝得到候选对，只有互相重叠的包围盒才进入窄相位；
  无限平面没有包围盒，单独与每个醒着的动态体配对。`broadphasePairs()` 与步进共用同一份剪枝实现，
  不存在"查询用一套、求解用另一套"的分裂。
- **谁是动态体由规则决定**：只有至少一侧是"醒着的动态体"时接触才可能改变状态，静态-静态、
  休眠-静态、休眠-休眠都不进入窄相位。
- **id 查找是 O(1)**：世界维护 `id → 下标` 映射，`bodyPosition`/`bodyShape`/`bodyState` 等按 id 的访问
  不再线性扫描；删除体会重建映射（O(n)，但删除远少于查询）。
- **位姿归一化只有一条规则**：`ShapeCollision::normalizedRotation` 负责归一化并校验，
  调用方不要自己写 `rotation / length(rotation)`——那样会在校验之前先产生 NaN。
- **诊断值**：`lastNarrowphasePairCount()` 返回上一步真正进入窄相位的形状对数量，
  用于确认剪枝生效（分离物体不产生候选对）；它不是模拟状态，不参与求解。

## 核心用法

### 静态世界与查询

```cpp
#include "physics/world/PhysicsWorld.h"

PhysicsWorld world;
world.setGravity({0.0f, -9.81f, 0.0f});

// 无限地面：平面用点法式描述，满足dot(normal, x) = offset的点在平面上。
PhysicsFilter terrain;
terrain.layer = PhysicsLayers::Terrain;
world.createStaticBody(CollisionShape(PlaneShape({0.0f, 1.0f, 0.0f}, 0.0f)), {0.0f}, glm::quat(1, 0, 0, 0), terrain);

// 墙体：位置与旋转都会参与碰撞；静态体不支持缩放。
world.createStaticBody(CollisionShape(BoxShape({0.5f, 2.0f, 5.0f})), {2.0f, 2.0f, 0.0f});

// 射线检测：返回最近命中，包含句柄、距离、命中点与法线（法线朝射线来向）。
if (auto hit = world.raycast(Ray(origin, direction), 60.0f))
{
    placeAt(hit->hit.point + hit->hit.normal * 0.01f);
}

// 形状重叠查询：返回全部重叠体与接触信息；pushOutNormal用于把查询形状移出该体。
for (const auto &overlap : world.overlapShape(shape, position, rotation))
{
    position += overlap.pushOutNormal * overlap.contact.penetration;
}
```

### 角色控制器

```cpp
CharacterSettings settings;
settings.radius = 0.35f;
settings.cylinderHeight = 1.0f;         // 总高 = cylinderHeight + 2 * radius
settings.maximumSlopeAngleDegrees = 46.0f;
CharacterController controller(settings);

CharacterState state;                    // position / velocity / grounded / groundNormal
// 每帧：调用方决定重力与跳跃，move只负责碰撞、滑动与着地判定。
state.velocity.y += world.gravity().y * deltaTime;
if (state.grounded && jumpRequested) { state.velocity.y = jumpSpeed; }
state = controller.move(world, state, deltaTime);
```

- `move` 内部把位移拆成不超过半径一半的子步，避免高速穿过薄墙；每次子步最多沿表面滑动
  `maximumSlideIterations` 次，次数用尽后丢弃剩余位移，不会穿墙。
- 着地判定使用可站立面（法线与向上方向的夹角不超过设定角度）。离地不超过 `groundSnapDistance`
  的可行走面会把角色贴回地面，因此下坡不会反复腾空。
- 高于角色半径的障碍会挡住角色；矮于半径的台阶会被圆角底面"骑"上去，这是球底/胶囊底穿透修正的
  几何结果，不是显式的踏升功能。

### 动态刚体

```cpp
RigidBodySettings settings;
settings.mass = 1.0f;
settings.restitution = 0.45f;
settings.friction = 0.4f;

// 首版只支持球体动态体；盒体/胶囊需要OBB对OBB等窄相位，会抛std::invalid_argument。
const PhysicsBodyId ball = world.createDynamicBody(CollisionShape(SphereShape(0.3f)), {0.0f, 3.0f, 0.0f}, settings);
world.setBodyVelocity(ball, {1.0f, 0.0f, 0.0f});
world.setBodyAngularVelocity(ball, {0.0f, 3.0f, 0.0f});
world.applyImpulse(ball, {0.0f, 2.0f, 0.0f});   // 会唤醒休眠体

world.step(deltaTime);                          // 固定步长推进，返回实际执行步数
if (auto state = world.interpolatedBodyState(ball, world.interpolationAlpha()))
{
    object.transform.position = state->position;
    object.transform.setRotation(state->rotation);
}
```

- `step(frameDeltaTime)` 把帧时间累加到固定步长（默认 1/60 秒），单帧最多补跑 4 步；超过上限的时间
  被丢弃，避免卡顿后一次补跑大量物理步。物理位姿的抖动由渲染插值消除。
- 求解为顺序冲量 + 位置修正：恢复系数在接近速度低于阈值时不生效，否则静止物体永远无法休眠；
  位置修正保留 `slop`，因此静止物体会留下毫米级穿透。
- 休眠条件为线速度与角速度同时低于阈值并持续 `sleepTime`；被冲量、被运动中的物体撞击或
  `setBodyTransform` 时唤醒。
- **接触不产生力矩**：球体不会因为摩擦而滚动加速，角速度只由应用设置和阻尼改变。

### 碰撞层与掩码

```cpp
PhysicsFilter prop;
prop.layer = PhysicsLayers::Prop;    // 我在哪些层
prop.mask  = 0xFFFFFFFFu;            // 我愿意与哪些层碰撞

// 两个体真正碰撞需要双方掩码都包含对方层；单方面同意不生效。
PhysicsFilter terrain{PhysicsLayers::Terrain, 0xFFFFFFFFu};

// 查询用一个掩码筛选对方层：只检测地形层，就不会被道具挡住。
const auto hit = world.raycast(ray, 100.0f, PhysicsLayers::Terrain);
```

### 场景组件

```cpp
// 以物体当前位姿注册静态体；物体被删除或组件析构时自动注销。
object.setPhysicsBody(world, CollisionShape(BoxShape({0.5f})), prop);
object.physicsBody().syncFromTransform(object.transform);  // 物体移动后同步
object.clearPhysicsBody();
```

生命周期规则与 `Renderable` 一致：组件借用世界与物体的 Transform。
**`PhysicsWorld` 必须比 `Scene` 活得更久**，否则 Scene 销毁时组件会向已销毁的世界注销句柄。
示例在 `main` 里用 `shared_ptr` 持有世界，让它在 `Application` 析构之后才释放。平面形状不能作为物体组件注册，静态地形请直接注册到世界。

## 示例层与框架的边界

- `physics_demo` 的运动、按键、摄像机、生成节奏和摆放全部属于示例层。
- 台阶、斜坡、方块布局属于示例；形状生成、碰撞、查询、求解、插值属于框架。
- `player_controller` 保留原来的"无限平地移动"演示，用于说明输入→指令→移动的分层；
  它的固定高度**不是**碰撞，需要真实碰撞请参考 `physics_demo`。
- 角色不与动态刚体交互：角色不是物理体，`RigidBodySettings` 也不会被角色推动。示例把球放在
  独立层，角色掩码不包含该层，因此角色会穿过球而不是被卡住。

## 明确不支持

关节与约束、软体/布料、触发器进入/离开事件、CCD、多线程、GPU 物理、盒体对盒体的动态碰撞、
胶囊对球体/胶囊的窄相位、动态体的接触力矩与滚动、运动平台载人、场景存档中的物理体恢复。
以上任何一项需要实现时，应先补充[实施计划](物理系统实施计划.md)再动手，不把"示例能跑"当作已经支持。

## 测试覆盖

`-L cpu` 分组的无窗口测试：

- `physics_shapes_test`：形状构造校验、局部包围盒、平面没有有限包围盒。
- `physics_math_test`：AABB 相交/包含/变换、射线归一化、最近点。
- `physics_raycast_test`：球/盒/平面/胶囊的命中、未命中、起点在形状内部、双面平面。
- `physics_collision_test`：各支持组合的接触法线与穿透深度、顺序无关的法线取反、
  胶囊对盒体（含旋转盒体）。
- `physics_world_test`：句柄生命周期、移动静态体后的查询、`maxDistance`、重叠查询、
  broadphase 候选对与 1000 个静态盒的参考耗时、删除中间物体后 id 映射仍指向正确数据。
- `physics_body_component_test`：组件注册/注销、物体删除后世界无残留。
- `physics_character_test`：落地高度、撞墙滑动、可行走/不可行走斜坡、矮台阶与高障碍、跳跃、
  着地吸附、层掩码、非法输入。
- `physics_rigidbody_test`：自由落体、弹性/非弹性碰撞、静止与休眠、球体互撞、重叠分离、
  冲量与唤醒、渲染插值、层过滤、扫掠剪枝的窄相位对数（50 个分离球只与平面配对，休眠对上不进入窄相位）。

`-L graphics` 分组的 `infinite_example_physics_demo_smoke` 启动真实示例，隐藏窗口绘制三帧并检查像素。
