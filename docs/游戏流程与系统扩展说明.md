# 游戏流程与系统扩展说明

这一轮把“从能渲染场景到能组织小游戏流程”所需的基础骨架补齐了。各模块仍保持窄职责，游戏规则由应用层注入。

## 推荐的主循环关系

```text
Window/Input
    ↓
ApplicationStateStack 提交上一帧状态切换
    ↓
SceneManager 提交下一关卡请求
    ↓
Application 更新 Scene / PhysicsWorld / Area
    ↓
Scene 渲染
    ↓
UiCanvas、应用扩展绘制
    ↓
AudioEventQueue → MusicPlayer → AudioSystem
```

状态栈决定“当前是哪一段流程”，SceneManager决定“当前是哪一关”，Scene保存关卡对象，UI显示流程，AudioEventQueue和AnimationEvent回调把表现层动作推给音频或粒子等服务。

## 关卡切换

```cpp
application.sceneManager().registerScene("level_01",
    [](Scene &scene, ResourceManager &resources)
    {
        (void)resources;
        scene.createObject("Player");
    });

application.sceneManager().requestLoad("level_01");
```

请求会在Application事件阶段提交，不会在 `Scene::update` 遍历中清空对象。第一阶段是同步Loader；Loader失败时半成品会被清理，当前名称不会伪装成已加载成功。

## Trigger / Area

```cpp
auto &area = scene.createObject("GoalArea");
area.setArea(application.physicsWorld(), CollisionShape(BoxShape({2, 1, 2})));
area.area().setBodyEnteredCallback([](PhysicsBodyId body)
{
    // 游戏层根据body句柄查找玩家，并请求进入结果状态。
    (void)body;
});
```

Area不是PhysicsBody，不产生推力和碰撞响应。它在固定物理步完成后对重叠集合做差，生成一次性的进入/离开事件。回调中应记录请求，让应用在安全阶段修改Scene，不要依赖回调过程中删除正在查询的物体。

## 动态物理第一阶段

动态刚体目前支持球体、重力、速度、固定步积分、阻尼、摩擦、恢复系数、冲量、休眠和一次固定步力：

```cpp
application.physicsWorld().applyForce(body, {0, 20, 0});
```

力在下一固定步积分后自动清零；持续推力要由应用每个固定步重新施加。动态盒体、胶囊、关节、CCD和力矩仍没有偷偷用球体近似，后续应分别补窄相位和约束求解。

## 音频和动画事件

`MusicPlayer`只管理音乐Voice和淡入淡出，资源仍由AudioSystem加载：

```cpp
application.music().play(clip, {}, 1.0f);
application.audioEvents().stopMusic(0.5f);
```

动画事件只携带时间和名称：

```cpp
player.setEventCallback([&](const AnimationEvent &event)
{
    if (event.name == "footstep")
    {
        // 由应用把脚步事件转成AudioEventQueue事件。
    }
});
```

动画模块不会直接依赖AudioSystem或ParticleSystem，避免资源和线程职责耦合。

## 粒子

`ParticleSystem`目前是可测试的CPU粒子数据层：它负责发射、生命周期、加速度、颜色和大小渐变，渲染层以后可以消费 `particles()` 做点精灵或实例化绘制。先把模拟数据和表现渲染拆开，避免粒子逻辑直接绑定某一种OpenGL绘制方案。

## 存档

```cpp
SaveGameData save;
save.activeScene = application.sceneManager().currentName();
save.values["score"] = std::int64_t(100);
SaveGameSerializer::save(application.scene(), save, "saves/slot_0");
```

存档目录包含 `state.save` 和 `scene.scene`。格式有版本号，字符串和数值有大小/类型校验，写入使用临时目录再提交。当前不会把C++回调、Voice句柄、动画播放器时间或动态刚体瞬时速度直接写进去；这些状态应转换成稳定的游戏字段后由应用保存。
